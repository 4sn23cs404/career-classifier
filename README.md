\# 🧠 CareerClassify - AI Resume Analyzer



AI-powered web application that analyzes resumes and recommends career paths based on skills, certifications, and interests.



\## ✨ Features



\- 📄 PDF resume upload and parsing

\- 🤖 AI-powered career classification

\- 📊 Confidence scores for top 3 career matches

\- 🎨 Beautiful, modern UI with animations

\- ⚡ Real-time analysis



\## 🚀 Career Categories



\- 🌐 Web Development

\- 📱 Mobile App Development

\- 📊 Data Science

\- ☁️ Cloud/DevOps

\- 🔌 IoT/Embedded Systems

\- 💻 Software Development



\## 🛠️ Tech Stack



\*\*Frontend:\*\*

\- React.js

\- Tailwind CSS

\- Lucide Icons



\*\*Backend:\*\*

\- Python Flask

\- PyPDF2 (PDF parsing)

\- Natural Language Processing
